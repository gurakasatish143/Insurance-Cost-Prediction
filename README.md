# Insurance-Cost-Prediction

A project focused on predicting insurance costs using data analysis and machine learning.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Activities

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Feature selection
- Machine learning model training
- Model evaluation

## Project Objective

To analyze insurance-related data and build a machine learning model to predict insurance costs based on available features.

## Project Type

Data Analytics / Machine Learning
